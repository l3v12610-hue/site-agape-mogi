Igreja Evangélica Missionária Ágape Mogi

Website institucional desenvolvido para a Igreja Evangélica Missionária Ágape Mogi, com o objetivo de apresentar a igreja, compartilhar seus horários de atividades e facilitar o contato com os visitantes.

Acesse o projeto: "Visualizar site" (https://l3v12610-hue.github.io/site-agape-mogi/)

Sobre o projeto

Este projeto foi desenvolvido como uma experiência prática de desenvolvimento web, aplicando conceitos de estruturação, estilização e interatividade.

Funcionalidades

- Apresentação institucional da igreja.
- Seção sobre a igreja.
- Horários dos cultos e atividades.
- Localização integrada com Google Maps.
- Acesso ao Instagram e WhatsApp.
- Navegação com rolagem suave.
- Layout adaptável a diferentes telas.

Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Google Maps Embed

Como executar localmente

1. Clone este repositório:
   "git clone https://github.com/l3v12610-hue/site-agape-mogi.git"
2. Abra a pasta do projeto.
3. Execute o arquivo "index.html" no navegador.

Objetivo de aprendizado

Praticar desenvolvimento front-end, organização de páginas web, estilização com CSS e implementação de interações com JavaScript.
