Igreja Ágape Mogi — Website

Website institucional desenvolvido para a Igreja Evangélica Missionária Ágape Mogi, com o objetivo de apresentar a igreja, divulgar os horários de cultos e facilitar o acesso às informações de contato e localização.

Sobre o projeto

O site reúne as principais informações institucionais em uma única página, com navegação por seções e uma identidade visual baseada em tons de verde-turquesa.

Funcionalidades

- Página inicial com apresentação da igreja.
- Navegação entre as seções do site.
- Seção institucional com a missão da igreja.
- Exibição dos horários de cultos e Escola Bíblica Dominical.
- Mapa incorporado para facilitar a localização.
- Links para Instagram e WhatsApp.
- Elementos visuais animados e rolagem suave entre seções.
- Layout adaptável para telas menores.

Tecnologias utilizadas

- HTML5 — estrutura e conteúdo.
- CSS3 — estilos, layout, animações e responsividade.
- JavaScript — interações, rolagem suave e criação dinâmica de partículas.
- Google Maps Embed — mapa de localização.

Estrutura do projeto

site-agape-mogi/
├── index.html
└── logo.png

O CSS e o JavaScript estão incorporados ao arquivo "index.html".

Como visualizar

1. Faça o download ou clone este repositório.
2. Mantenha "index.html" e "logo.png" na mesma pasta.
3. Abra o arquivo "index.html" em um navegador.

Objetivo de aprendizado

Este projeto foi uma oportunidade de praticar a criação de uma página institucional, organização de conteúdo, estilização com CSS, interações com JavaScript e adaptação da interface para dispositivos móveis.

Ágape Mogi Church — Website

An institutional website developed for Igreja Evangélica Missionária Ágape Mogi, designed to introduce the church, share service schedules, and make contact and location information easier to access.

Project overview

The website brings essential institutional information together on a single page, with section-based navigation and a visual identity built around turquoise-green tones.

Features

- Homepage introducing the church.
- Navigation between website sections.
- Church mission and institutional information.
- Service and Sunday Bible School schedules.
- Embedded map for location.
- Instagram and WhatsApp links.
- Animated visual elements and smooth scrolling.
- Responsive layout for smaller screens.

Technologies

- HTML5 — structure and content.
- CSS3 — styling, layout, animations, and responsiveness.
- JavaScript — interactions, smooth scrolling, and dynamic particle effects.
- Google Maps Embed — location map.

Project structure

site-agape-mogi/
├── index.html
└── logo.png

CSS and JavaScript are currently embedded in "index.html".

How to view

1. Download or clone this repository.
2. Keep "index.html" and "logo.png" in the same folder.
3. Open "index.html" in a web browser.

Learning goals

This project provided an opportunity to practice building an institutional webpage, organizing content, styling with CSS, adding JavaScript interactions, and adapting an interface for mobile devices.
